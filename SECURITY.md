# Security Policy

## Reporting a Vulnerability

Nao exponha credenciais AWS, kubeconfigs, ARNs sensiveis ou dados reais de ambiente em issues publicas.

- Email: tharlesson@msn.com
- Inclua impacto, passos de reproducao e contexto tecnico seguro para compartilhamento.

## Escopo

Este repositorio gerencia EKS, IAM, interrupcoes Spot, manifests de Karpenter e automacoes operacionais. Trate com cuidado tudo que envolva cluster names, policies IAM e configuracoes de rede.
